Disciplinas

Alunos e ex-alunos tem acesso aos seus documentos, disponibilizados no portal do aluno.

Para acessar, faça login com seu usuário (nome.sobrenome) e senha. Se não tiver ou não lembrar, recupere por este  link: https://senha.ufes.br/site/recuperaCredenciais 

Localize as informações do seu curso, no menu à esquerda (do portal). São documentos como, Planos de Ensino, Programas de disciplinas,  Ementas das Disciplinas Cursadas, Histórico, Currículo do curso, entre outros.

 

OBS.: Se os Planos de Ensino ou Programas de Disciplinas estiverem incompletos encaminhe esses documentos (em branco), juntamente com o seu Histórico e com o relatório das Ementas das Disciplinas Cursadas para que possamos localizá-los nos arquivos físicos e providenciar o preenchimento via portal.

Email: sid.cchn.ufes@gmail.com

 

Os programas que competem a esta secretaria iniciam com os códigos BIO, CSO, DLE, DLT, DLV, ERN, FIL, GEO, HIS, LET e PSO.

Para programas iniciados com outros códigos, faça contato com os departamentos que as ofertam (veja o contato nas páginas dos respectivos Centros de Ensino:

Disciplinas com Código – PSI - Centro de Ciências Humanas e Naturais (CCHN)

Disciplinas com Código - STA / FIS / MAT / QUI - Centro de Ciências Exatas (CCE) 

Disciplinas com Código - MOR / PAT / FSI / etc. - Centro de Ciências da Saúde (CCS) 

Disciplinas com Código – ADM / ARQ / BIB / COM / ECO / DIR / GEM / SSO - Centro de Ciências Jurídicas e Econômicas (CCJE) 

Disciplinas com Código - EPS / LCE / TEP / DAD / DID / ADE / EDU (3 Departamentos) - Centro de Educação (CE)
